## 📜 Descrição

Este repositório documenta a minha jornada no **Bootcamp Bradesco - GenAI, Dados & Cyber**, uma formação completa com foco prático em Inteligência Artificial Generativa, Análise de Dados e Cibersegurança.

## 🎯 Objetivos do Bootcamp

- Desenvolver fundamentos em Inteligência Artificial Generativa e Prompt Engineering.
- Aprender análise, tratamento e visualização de dados utilizando Excel, SQL e Python.
- Compreender e aplicar práticas essenciais de Cibersegurança e segurança digital.
- Criar soluções inteligentes e automatizadas aplicáveis a cenários reais de produtividade e segurança.
- Consolidar os conhecimentos por meio de projetos práticos, acompanhando as principais demandas do mercado.

## 📂 Projetos Desenvolvidos

### 1. Caderno Temático com NotebookLM
Uso de IA como ferramenta de aprendizagem ativa para estudar detecção de fraudes financeiras, métodos, desafios e proteção de dados.

### 2. Desafio Criativo — Insights de Feedback Bancário
Uso de engenharia de prompts para analisar feedbacks de clientes, extrair insights e identificar oportunidades de melhoria com apoio de IA e atenção à proteção de dados.
